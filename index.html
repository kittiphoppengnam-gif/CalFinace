02
Piecewise Function แปลงเป็นคะแนน 0-100
ม.ปลาย
แต่ละ ratio มีเป้าหมายต่างกัน เราใช้ฟังก์ชันเป็นช่วงเพื่อแปลงทุก ratio ให้เป็นคะแนน 0-100 เปรียบเทียบกันได้ ตัวอย่างของอัตราการออม:
⎧ 0 ถ้า x ≤ 0
f(x) = ⎨ 100·(x/0.20) ถ้า 0 < x ≤ 0.20
⎩ 100 ถ้า x > 0.20
คะแนนแต่ละมิติของคุณ

Score = w₁·S_ออม + w₂·S_ฉุกเฉิน + w₃·S_หนี้ + w₄·S_ลงทุน

weights = [0.25, 0.30, 0.25, 0.20]

04
Future Value of Annuity
ม.ปลาย
คำแนะนำที่บอก "ต้องเก็บอีกกี่เดือนถึงเป้า" คำนวณจากสูตรเงินรายงวด โดยให้ดอกเบี้ย 1.5% ต่อปี (บัญชีออมทรัพย์ดิจิทัล)
FV = PMT × [((1+r)ⁿ - 1) / r]

หาจำนวนเดือน n เมื่อรู้ FV เป้าหมาย:
n = log(1 + FV·r/PMT) / log(1 + r)
เวลาถึงเป้ากองทุนฉุกเฉิน 6 เดือน

05
Z-Score เทียบกับคนวัยเดียวกัน
ม.ปลาย
ใช้สถิติบอกว่าคุณดีกว่า/แย่กว่าค่าเฉลี่ยกี่ส่วนเบี่ยงเบนมาตรฐาน สมมติคนวัย 30 ออมเฉลี่ย 15% (μ) ส่วนเบี่ยงเบน 8% (σ)
z = (x - μ) / σ

z > 0 → ดีกว่าค่าเฉลี่ย
z > 1 → top ~16% ของคนวัยเดียวกัน
z > 2 → top ~2.5%
Z-score อัตราการออมของคุณ
